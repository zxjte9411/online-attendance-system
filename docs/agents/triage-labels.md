# Triage labels

Use these five canonical triage labels. A ticket should normally have the one
label that best describes its current handoff state.

| Label | Meaning | Use when |
| --- | --- | --- |
| `needs-triage` | Needs triage | The issue is new or has not yet been assessed. |
| `needs-info` | Needs information | The report lacks information required to assess or implement it. |
| `ready-for-agent` | Ready for agent | The issue is sufficiently specified and can be implemented by an agent. |
| `ready-for-human` | Ready for human | The issue needs a human decision, review, access, or intervention. |
| `wontfix` | Won't fix | The issue is intentionally not going to be addressed. |

Move the ticket to the next applicable label as triage progresses. When using
`wontfix`, record the reason in an issue comment before closing the issue.
